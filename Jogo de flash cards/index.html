Flash Cards - Programação

O que é HTML?

O HTML (HyperText Markup Language, ou Linguagem de Marcação de Hipertexto) é a linguagem padrão utilizada para criar e estruturar páginas na internet.

O que é CSS?

(Cascading Style Sheets, ou Folhas de Estilo em Cascata) é uma linguagem de estilo usada para definir a aparência e o design de páginas da web escritas em HTML ou XML.

O que é JavaScript?

É uma linguagem de programação que adiciona interatividade às páginas.

O que é uma variável?

É um espaço utilizado para armazenar um valor.

O que é um algoritmo?

É uma sequência de instruções para resolver um problema.
