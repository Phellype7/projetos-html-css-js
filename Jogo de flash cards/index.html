Flash Cards - Programação

O que é HTML?

É uma linguagem de marcação usada para estruturar páginas web.

O que é CSS?

É uma linguagem usada para estilizar páginas web.

O que é JavaScript?

É uma linguagem de programação usada para adicionar interatividade às páginas.

O que é uma variável?

É um espaço utilizado para armazenar um valor.

O que é um algoritmo?

É uma sequência de instruções para resolver um problema.
